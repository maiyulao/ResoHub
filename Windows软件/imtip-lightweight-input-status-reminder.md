## 内容预览

ImTip 是一款极简的 Windows 通用输入法状态提示工具。它能将当前的输入状态（中英文、全半角等）实时显示在光标位置，让你无需低头查看任务栏托盘即可确认输入状态，极大提升输入效率。 核心特性 广泛的兼容性： 基于通用的 IMC_GETCONVERSIONMODE 消息，理论上支持所有主流输入法，包括微软拼音、搜狗、百度、QQ 输入法等。 精准的实时提示： 能够实时获取输入框或鼠标光标位置，仅在状态切换时显示数秒（时长可自定义），…
