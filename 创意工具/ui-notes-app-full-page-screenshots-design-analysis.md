## 文章看点

厌倦了无法落地的“飞机稿”？这里为你推荐一个专注于真实产品的灵感库 UI Notes，涵盖 112 个主流 App 的 2 万多张全页截图。你可以通过研究这些经过市场验证的真实界面，快速拆解竞品逻辑并高效获取可复用的设计方案。

## 内容预览

寻找真实的产品设计灵感，该去哪里？ 在进行 UI 设计时，设计师常面临一个困境：许多设计平台充斥着精美但无法落地的“飞机稿”，缺乏实际产品在复杂业务场景下的真实表现。当你需要分析竞品逻辑、研究最新交互趋势，或者在紧迫的截稿期限前快速寻找可参考的界面方案时，一个纯粹的、基于真实产品的灵感库就显得至关重要。 UI Notes 正是为了解决这一痛点而生。由设计师 muxin 开发，它摒弃了虚幻的视觉概念，专注于收集国内优秀 App 的真实界面…
