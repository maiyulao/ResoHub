## 文章看点

告别繁琐的重复登录，这款开源插件让你在同一个B站页面即可快速切换多个账号，极大提升多号操作效率。此外，它还集成了评论增强、直播助手及视频封面获取等实用工具，是B站重度用户的全方位增强利器。

## 内容预览

Btools (逼砣)：B站增强与多账号快速切换插件 Btools 是一款基于 TypeScript 和 Vue 开发的开源 Chrome 扩展，旨在通过功能增强优化 B 站的网页浏览体验。其核心亮点在于解决了多账号操作繁琐的痛点：用户无需在多个浏览器之间切换或频繁登入登出，即可在同一个页面快速切换账号进行互动。 核心功能清单 多账号管理：支持 B 站账号快速切换，无需刷新页面即可更改互动身份。 评论增强：集成历史表情记录、评论内容搜索…
