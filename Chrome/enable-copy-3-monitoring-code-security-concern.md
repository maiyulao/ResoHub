## 文章看点

警惕 Enable Copy 3.0 插件被曝植入监控代码，可能导致您的浏览行为和网络请求数据在后台静默泄露。建议立即卸载该插件，并参考文中提供的安全替代方案，通过透明度更高的油猴脚本实现网页限制解除，确保隐私安全。

## 内容预览

Enable Copy 3.0 版本被曝包含监控代码 近日，V2EX 用户 EridanusSora 披露，Chrome 浏览器扩展 Enable Copy 3.0 版本中被发现植入了监控脚本。该脚本通过 chrome.webRequest 接口实时监听用户的所有网络请求，并将相关数据加密后发送至远程服务器 https://analytics2.zoomcorder.com。 这意味着该扩展可能会在后台静默收集用户的浏览行为与网络请求数…
