## 文章看点

厌倦了内网传文件时的繁琐操作？这款开源工具 netSend 支持跨平台无缝传输，且完全没有文件大小限制，让大型安装包或高清视频在设备间秒传。文中提供了详细的部署指南与资源下载，助你快速搭建起一个极简的局域网文件分享系统。

## 内容预览

什么是 netSend？ netSend 是一款基于 umijs、electron 和 javascript 开发的开源局域网文件传输工具。它旨在解决内网环境下设备间传文件繁琐的问题，支持跨系统、跨终端的无缝传输，且对传输文件的大小没有限制。 该工具的操作逻辑极其简单：用户仅需安装客户端，将文件拖拽至软件界面即可完成上传。系统会自动生成对应的文件链接，支持通过复制链接或扫描二维码快速分享给同一局域网内的其他设备。 功能特性与适用场景 跨…
