## 内容预览

认识 TTS Importer TTS Importer 是一款专门为阅读爱好者设计的工具，旨在将微软 Azure TTS 的高质量语音合成服务无缝集成到各类第三方阅读软件中。通过该工具，用户可以摆脱单一的系统语音，在阅读小说时享受更自然、更具人性化的 AI 朗读体验。 支持的阅读软件 TTS Importer 具有广泛的兼容性，目前可将 Azure TTS 服务导入至以下主流阅读应用： 阅读 (Legado) 爱阅记 爱阅书香 源阅读…
