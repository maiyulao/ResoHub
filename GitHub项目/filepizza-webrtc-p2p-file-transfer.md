## 文章看点

想要快速、私密地传输大文件却不想安装软件？FilePizza 让你无需经过中转服务器，直接通过浏览器实现点对点极速传输，且支持多文件一键打包下载。无论是跨设备办公还是传输敏感素材，都能在确保数据不留痕迹的同时，享受无需安装客户端的便捷体验。

## 内容预览

什么是 FilePizza？ FilePizza 是一款基于 WebRTC 技术的开源浏览器端点对点（P2P）文件传输工具。与传统的云盘或文件传输服务不同，它无需经过中转服务器，数据在发送者与接收者之间直接流动，从而确保了传输的高效性与私密性。 该工具完全运行在浏览器中，兼容 PC 与移动端。用户无需安装客户端，即可通过网页快速分享文件。为了保障数据安全，FilePizza 全程采用公钥加密，并支持设置密码，为敏感文件提供额外的保护层。…
