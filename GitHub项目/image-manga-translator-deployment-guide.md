## 文章看点

想要快速翻译漫画且不破坏原图排版？本文为你提供 Image/Manga Translator 的详细部署指南，带你实现自动修补背景并原位替换文字的无缝“嵌字”效果。通过简单的 Docker 托管，你就能搭建起一套支持日、英、韩多语言的私有图片翻译服务。

## 内容预览

Image/Manga Translator：开源漫画与图片翻译工具 Image/Manga Translator 是一款基于 Python 开发的开源翻译项目，专门用于处理图片及漫画中的文字翻译。该工具不仅能快速识别图像中的文本，还能将翻译后的中文直接覆盖在原位置，实现无缝的“嵌字”效果。 核心功能与特性 原位替换： 支持自动修补原图背景并填入翻译文本，保持漫画排版完整。 多语言支持： 重点优化了日语翻译，同时兼容中文、英文和韩语。 …
