## 文章看点

想要快速评估 Linux 服务器的真实性能？本文为你提供轻量级工具 YABS 的操作指南，只需运行一行简单指令，即可一键获取磁盘 I/O、网络带宽及 CPU 算力的专业跑分数据。

## 内容预览

什么是 YABS？ YABS（Yet Another Bench Script）是一款专为 Linux 服务器设计的轻量级性能测试脚本。它将 fio、iperf3 和 Geekbench 等专业工具集成在一起，允许用户通过一条指令快速评估 VPS 的综合性能。 该脚本主要覆盖以下测试维度： 磁盘 I/O： 测试硬盘的随机读写速度。 网络带宽： 测量服务器的实际下载速度。 CPU 算力： 提供 Geekbench 4 和 5 的跑分结果。…
