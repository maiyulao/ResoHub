## 文章看点

想要摆脱商业翻译 API 的限制并彻底掌控数据隐私吗？本文为你详细介绍开源的 LibreTranslate 方案，让你能够快速构建一套完全私有化的机器翻译服务。你将获得一个可自由定制、无需向第三方供应商发送数据的翻译接口，完美解决隐私敏感项目的部署难题。
